# Municipal GIS Platform — Backend

NestJS + PostgreSQL (Prisma) API for municipality registration and tenant
context. See [../docs/backend.md](../docs/backend.md) for setup, migrations,
environment variables, and endpoint documentation.

Quick reference:

```bash
npm run start:dev    # dev server with hot reload
npm run build         # production build
npm test               # unit tests
npm run test:e2e       # integration tests (requires a reachable Postgres)
npm run lint            # eslint
```
